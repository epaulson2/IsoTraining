# Horizontal Pull / Row Family

## Status

**Validated family draft — primarily evidence-based extension.**

## Family role

The historical EVO core is much stronger on scapular pull-up than on horizontal rowing. This family fills that gap while preserving the system's emphasis on active intent, stable geometry and long-position control.

## Primary versions

### A. Body-Supported Row Iso
- **Type:** Integrated
- **Provenance:** Evidence-based extension
- **Use:** Whole-body horizontal pulling with trunk and scapular stabilization

### B. Strap Row Iso
- **Type:** Targeted
- **Provenance:** Evidence-based extension
- **Use:** Precise elbow/shoulder angle with high pulling intent

### C. Long-Arm Strap Row / Scapular Retraction Iso
- **Type:** Targeted
- **Provenance:** Evidence-based extension
- **Use:** Upper-back and scapular control with less elbow-flexor contribution

## Body-Supported Row Iso

### Setup

- Use a secure bar, rings, suspension handles or fixed support.
- Choose a body angle that allows clean control.
- Maintain a rigid trunk from head to pelvis.
- Start from a relatively lengthened shoulder position without passively hanging on the joint.
- Keep wrists neutral and elbows on a repeatable path.

### Active intent

Pull the torso toward the hands while preventing visible movement. Maintain active scapular control and avoid turning the hold into a shrug or biceps-only effort.

### Learn Mode

1. Establish grip and body line.
2. Learn trunk stiffness independently.
3. Practice a shallow row to find elbow path.
4. Find the lengthened working position.
5. Create gentle scapular tension.
6. Add elbow-flexion / lat pulling intent.
7. Increase force while body angle stays fixed.
8. Hold 8–15 seconds cleanly.
9. Step out rather than dropping from fatigue.

### Workout-mode cues

**Rigid trunk • shoulders active • pull chest toward hands**

## Strap Row Iso

### Setup

- Anchor or route the non-elastic strap securely in front of the body.
- Set the strap length so the shoulder is flexed enough to create a meaningful long position.
- Keep spine and pelvis neutral.
- Use a comfortable elbow path.

### Active intent

Pull the handles toward the torso as hard as prescribed while the strap prevents movement.

### Learn Mode

1. Establish safe anchor geometry.
2. Set shoulder angle.
3. Set wrist and elbow alignment.
4. Organize ribs and pelvis.
5. Create low-level scapular tension.
6. Add row intent.
7. Build force gradually.
8. Hold 6–10 seconds without leaning backward.

### Common compensations

- leaning back to manufacture force;
- shrugging;
- excessive elbow flare;
- wrists flexing;
- losing the selected shoulder angle.

### Workout-mode cues

**Stay tall • keep shoulders organized • row hard without leaning**

## Rationale

Horizontal pulling is not strongly represented in the classic seven-position EVO sequence, so this family is included as a transparent extension for balanced shoulder-girdle programming.
