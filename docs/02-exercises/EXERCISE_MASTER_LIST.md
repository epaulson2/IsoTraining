# IsoTraining Exercise Master List

## Purpose

This is the canonical inventory of movement families and exercise variants for the IsoTraining project. Programming should select from this library rather than introduce new exercises ad hoc.

## Provenance

- **EVO Original** — directly described in Schroeder/EVO material or documented by trainees receiving EVO instruction.
- **Schroeder-Derived** — close interpretation or teaching regression preserving the original concept.
- **Evidence-Based Extension** — our application of isometric, long-muscle-length and biomechanics principles.

## Programming rule

The library intentionally balances:

1. **Integrated positions** for whole-body stabilization and coordination.
2. **Targeted strap/support positions** for precise force production at selected joint angles.

Advanced programming should progress methods as much as exercises: assisted position → standard Extreme Iso → longer accumulated work → higher intent / load → Extreme Slow → force-absorption / rebound pairing where appropriate.

## Current status

All 13 movement families now have initial technical specifications and Learn Mode logic. Some individual movements remain explicitly provisional where historical documentation is incomplete or where final inclusion depends on programming value.
