# IsoTraining Exercise Master List

## Purpose

This is the canonical post-audit inventory of movement families and exercise variants for the IsoTraining project. Programming should select primarily from **Tier A**, use **Tier B** selectively, and treat **Tier C** as optional variations/accessories rather than default program content.

## Provenance

- **EVO Original** — directly described in Schroeder/EVO material or documented by trainees receiving EVO instruction.
- **Schroeder-Derived** — close interpretation or teaching regression preserving the original concept.
- **Evidence-Based Extension** — our application of isometric, long-muscle-length and biomechanics principles.

1. Split stance / lunge
2. Squat / knee-dominant
3. Hip hinge / hamstring
4. Horizontal push / chest
5. Vertical push / triceps
6. Vertical pull / scapular-lat
7. Horizontal pull / row
8. Elbow flexion / biceps
9. Calf / ankle plantar flexion
10. Adductor / lateral stance
11. Hip-flexor / long split
12. Shoulder rotation / stabilization
13. **Anterior chain / quadriceps** — renamed conceptually from “Quadriceps Long-Length” because the historical standing straight-leg raise is not globally a long-length quadriceps position.

## Programming rule

The library intentionally balances:

1. **Integrated positions** for whole-body stabilization and coordination.
2. **Targeted strap/support positions** for precise force production at selected joint angles.

Advanced programming should progress methods as much as exercises: assisted position → standard Extreme Iso → longer accumulated work → higher intent / load → Extreme Slow → force-absorption / rebound pairing where appropriate.
