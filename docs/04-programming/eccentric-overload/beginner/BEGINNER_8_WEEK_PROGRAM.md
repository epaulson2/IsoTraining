# Home Eccentric Overload — Beginner 8-Week Program

## Status

**Locked first-pass beginner program for the Core 6 home eccentric-overload system.**

This plan is designed to follow the [Core 6 Learning Guide](../../../03-position-learning/HOME_ECCENTRIC_OVERLOAD_CORE_6_LEARNING_GUIDE.md). The learning guide teaches the movement paths, leverage ladders, calibration zones, assisted resets, and escape strategies. This program turns those skills into a conservative eight-week progression.

The six Core movements are:

1. Ring Chest Press Eccentric
2. Ring Row Eccentric
3. Supported Sissy-Squat Eccentric
4. Assisted Nordic Hamstring Eccentric
5. Ring Fallout / Ab Rollout Eccentric
6. Assisted Pull-Up Eccentric

The governing principle is:

> **Get up with assistance. Choose the leverage. Fight the descent. Exit before form changes. Reset completely.**

This is a low-volume program on purpose. Eccentric overload can create high force and considerable soreness with very little work. Beginners do not need large rep counts or frequent maximal exposures.

---

# 1. Program objective

By the end of eight weeks, the trainee should be able to:

- independently set up all six Core exercises;
- identify Green, Blue, Orange, and Red loading without guessing;
- perform controlled eccentric reps without deliberately “acting slow”;
- use the planned escape/reset automatically;
- tolerate two weekly full-body eccentric sessions without excessive soreness;
- perform conservative Orange-zone work on the major movements while maintaining clean technique;
- choose an appropriate beginner/intermediate leverage level for each exercise;
- progress leverage by small changes rather than dramatic jumps.

The goal is **skillful eccentric overload**, not maximal suffering.

---

# 2. Weekly schedule

Use **two nonconsecutive full-body sessions per week**.

Good examples:

- Monday + Thursday
- Tuesday + Friday
- Wednesday + Saturday

Keep at least **48–72 hours** between hard sessions.

Do not add a third hard eccentric session during this beginner block.

### Optional recovery / skill day

A third day may be used only for:

- easy Green-zone movement rehearsal;
- mobility;
- normal walking / light cardio;
- setup practice;
- no hard eccentrics.

---

# 3. Session order

Use the same order during the beginner block so the routine becomes automatic:

1. **Ring Chest Press Eccentric**
2. **Supported Sissy-Squat Eccentric**
3. **Ring Row Eccentric**
4. **Assisted Nordic Hamstring Eccentric**
5. **Assisted Pull-Up Eccentric**
6. **Ring Fallout / Ab Rollout Eccentric**

This alternates upper and lower emphasis early in the session and keeps the rollout last, where trunk fatigue cannot compromise the other large patterns.

---

# 4. Warm-up and calibration sequence

Before the first work rep of each exercise:

## A. General warm-up — 4–6 minutes

Use easy movement such as:

- brisk walking;
- marching;
- arm circles;
- bodyweight squats;
- easy ring rows / presses;
- gentle hinges.

The goal is simply to feel warm and coordinated.

## B. Exercise-specific rehearsal

For every exercise:

1. Perform **1–2 easy Green reps** through the intended path.
2. Practice the escape/reset once.
3. Move to a **Blue calibration rep**.
4. Only after Blue is clean should the work leverage be selected.

Do not treat warm-up reps as working eccentrics.

---

# 5. The diagnostic descent window

The program does **not** prescribe an artificial tempo.

The athlete should always try to stop the movement.

Time is used only as a diagnostic:

- **under ~2 seconds:** usually too heavy / Red;
- **roughly 3–8 seconds:** commonly a useful controlled eccentric window;
- **10+ seconds or clearly stoppable:** often too easy for true overload, although still useful for learning.

These are coaching heuristics, not magic physiological thresholds.

If the rep takes 5 seconds because you are resisting as hard as possible, good.

If it takes 5 seconds because you intentionally chose to move at a 5-second tempo despite being able to stop, that is a different stimulus.

---

# 6. Rest rules

## Between eccentric reps

Take enough time to fully reset technique:

- usually **20–60 seconds**;
- longer if breathing or grip is not ready.

Each rep should begin fresh enough to reproduce the intended position.

## Between sets of the same exercise

Use **2–4 minutes**.

Nordics and pull-ups may require the longer end.

## Between exercises

Normally **1–3 minutes**, or simply the time needed to adjust equipment and feel ready.

---

# 7. Technical stop rules

End a rep immediately when any of the following occurs:

- sharp pain;
- joint pinching;
- numbness or tingling;
- sudden tendon pain;
- loss of trunk position;
- loss of shoulder / knee / hip alignment;
- uncontrolled acceleration;
- need to swing, kick, or bounce;
- planned escape is no longer available.

Do **not** count a collapsed rep as a successful repetition.

---

# 8. Soreness and recovery rule

Novel eccentric loading can create delayed soreness that is much larger than the apparent workout volume.

Use this rule before each session:

### Green light

- mild muscle soreness only;
- normal range of motion;
- no joint or tendon discomfort;
- daily movement feels normal.

Train as planned.

### Yellow light

- moderate soreness;
- movement feels stiff;
- muscle tenderness changes technique.

Stay in Blue and reduce total work by roughly one third to one half.

### Red light

- severe soreness;
- meaningful range-of-motion loss;
- tendon or joint pain;
- limping / altered daily movement;
- soreness worsening rather than improving.

Skip hard eccentric work until recovered.

Never try to “train through” sharp tendon pain.

# 9. Week-by-week progression

## Week 1 — Learn the system

### Goal

Technique, escape, and calibration.

### Frequency

2 sessions.

### Work prescription

For each Core 6 exercise:

- **1 work set**
- **1 eccentric rep**
- **Blue zone only**
- no deliberate supramaximal work

Before the work rep, perform the easy rehearsal / calibration sequence.

### What counts as success

- no Red-zone drops;
- clean escape/reset;
- soreness is mild and manageable;
- the trainee can describe where they felt the exercise.

### Week 1 rule

**Finish every session feeling like you could have done much more.**

---

## Week 2 — Repeatability

### Goal

Perform the same movements twice without technique drift.

### Work prescription

For each exercise:

- **1 set × 2 eccentric reps**
- Blue zone
- 20–60 sec reset between reps

Do not increase leverage and reps at the same time.

If Week 1 caused substantial soreness, remain at 1 rep.

### Progression target

Use approximately the same leverage as Week 1 unless it clearly feels Green.

---

## Week 3 — First overload build

### Goal

Increase exposure while keeping the method controlled.

### Work prescription

#### Chest press, ring row, sissy squat

- **2 sets × 2 reps**
- strong Blue
- optional very conservative Orange on the **final rep of the second set** only if technique is excellent

#### Nordic, pull-up, fallout

- **1 set × 2 reps**
- Blue only

These three movements remain lower volume because they are often more demanding for beginners.

### Orange gate

Only use Orange if:

- Blue is completely predictable;
- escape is automatic;
- no pain is present;
- the athlete can still maintain the intended body position.

---

## Week 4 — Consolidation

### Goal

Absorb the first three weeks rather than chase progression.

### Work prescription

All six exercises:

- **1 set × 1–2 reps**
- Blue zone
- use the same or slightly easier leverage than Week 3

This is approximately a 35–50% reduction in eccentric exposures.

### Do not

- test max leverage;
- add reps because the workout feels short;
- introduce advanced variations.

The short session is intentional.

---

## Week 5 — Controlled Orange introduction

### Goal

Begin true eccentric-overload practice on the most stable movements.

### Chest press, row, sissy squat

- **2 sets × 2 reps**
- first rep: Blue / Blue-Orange
- second rep: conservative Orange if control is perfect

### Nordic

- **2 sets × 1 rep**
- Blue to conservative Orange using assistance

### Pull-up

- **1–2 sets × 1 rep**
- strong Blue
- use chair/foot assistance throughout calibration

### Fallout

- **1 set × 2 reps**
- Blue

### Week 5 priority

The trainee should learn that Orange often requires only a **tiny leverage change** from Blue.

---

## Week 6 — Full Core 6 overload practice

### Goal

Expose every major pattern to controlled overload while keeping total volume low.

### Work prescription

#### Chest press / row / sissy squat

- **2 sets × 2 reps**
- Blue-to-Orange

#### Nordic / pull-up / fallout

- **2 sets × 1–2 reps**
- first rep Blue
- second rep may approach Orange if the first was technically excellent

### Rule

Do not let the second rep become worse merely because it is “supposed” to be harder.

If rep 1 was already Orange, rep 2 may use the same or easier leverage.

---

## Week 7 — Peak beginner build

### Goal

Highest-quality workload of the block, not a max test.

### Chest press / row / sissy squat

- **2 sets × 2–3 reps**
- Blue-to-Orange
- maximum **3 reps per set**

### Nordic / pull-up

- **2 sets × 2 reps**
- Blue-to-conservative-Orange

### Fallout

- **2 sets × 2 reps**
- Blue-to-Orange only while ribs and pelvis remain controlled

### Rep quality rule

The moment rep quality drops, the set is complete even if the written target says another rep is available.

### Week 7 cap

No exercise exceeds **6 hard eccentric reps in one session**, and most remain at 4.

---

## Week 8 — Consolidate and reassess

### Goal

Finish stronger and more skilled, not exhausted.

### Work prescription

All six exercises:

- **1–2 sets × 1–2 reps**
- Blue-to-conservative-Orange
- approximately 40% lower total exposure than Week 7

### Reassessment

For each exercise, record:

- current leverage level;
- current calibration zone;
- whether the current version is stoppable;
- whether a concentric reversal is possible;
- which escape strategy is used;
- any recurring technical limitation.

Do not perform maximal drops or “see how hard you can make it.”

The reassessment is a technique and leverage audit.

# 11. Exercise-specific beginner progression targets

## Ring Chest Press

### Weeks 1–2

Explore:

- near-upright;
- shallow lean;
- moderate lean only if Blue remains easy to control.

### Weeks 3–5

Build toward:

- moderate lean;
- deeper ring press.

### Weeks 6–8

Potentially explore:

- deeper / near-horizontal versions;
- only if shoulder position and escape remain excellent.

**Feet elevated and unilateral versions are not required for beginner graduation.**

---

## Ring Row

### Weeks 1–2

- upright to moderate lean.

### Weeks 3–5

- deeper lean;
- possibly near-horizontal.

### Weeks 6–8

- near-horizontal;
- optional slight foot elevation if clearly earned.

Archer and one-arm work remains post-beginner.

---

## Supported Sissy Squat

### Weeks 1–2

- high support;
- partial-to-moderate range.

### Weeks 3–5

- full supported range;
- slightly less hand assistance.

### Weeks 6–8

- reduced hand support and greater knee travel if pain-free.

Minimal-support / unilateral-bias work is optional and usually belongs later.

---

## Assisted Nordic

### Weeks 1–2

- high assistance;
- short range.

### Weeks 3–5

- moderate assistance;
- gradually longer range.

### Weeks 6–8

- light-to-moderate assistance;
- possibly brief unassisted portions of the range.

A full Nordic eccentric is **not** a beginner requirement.

---

## Ring Fallout / Ab Rollout

### Weeks 1–2

- upright standing fallout or short kneeling range.

### Weeks 3–5

- larger standing lean or moderate kneeling range.

### Weeks 6–8

- longer kneeling range.

Advanced standing long-lever work remains optional.

If the low back arches, immediately move back one level.

---

## Assisted Pull-Up

### Weeks 1–2

- high box / substantial foot support.

### Weeks 3–5

- lower box or lighter toe support.

### Weeks 6–8

- minimal foot assistance;
- possibly full bodyweight negative if earned.

A slow full unassisted eccentric is a strong beginner graduation achievement but is not mandatory for every trainee.

---

# 12. Progression hierarchy

When an exercise becomes easier, progress in this order:

1. **Perfect the setup and escape.**
2. **Own the current eccentric path.**
3. **Reduce unnecessary assistance.**
4. **Increase range slightly.**
5. **Change body angle / leverage slightly.**
6. **Move from Blue toward Orange.**
7. **Only later explore advanced unilateral or long-lever variations.**

Do not progress simultaneously by:

- adding reps;
- increasing range;
- reducing assistance;
- and making leverage harder.

Choose one main change.

---

# 13. Progression gate

Move to a harder leverage only when all of the following are true for **at least two sessions**:

- movement path is stable;
- no sharp pain or tendon discomfort;
- escape is automatic;
- current eccentric is controlled;
- current leverage is becoming clearly stoppable or reversible;
- normal soreness resolves before the next session.

If not, remain at the same level.

Calendar progression is optional. Technical progression is mandatory.

---

# 14. Beginner graduation criteria

The trainee is ready for an intermediate eccentric-overload block when they can:

1. set up all six exercises independently;
2. find Blue reliably without accidental Red loading;
3. find conservative Orange on at least the chest press, row, sissy squat, and one of the vertical-pull / hamstring patterns;
4. complete 2 quality sets on major exercises without technique deterioration;
5. use the assisted reset without adding unwanted concentric fatigue;
6. recover normally across two weekly sessions;
7. distinguish muscular soreness from tendon / joint pain;
8. progress leverage in small, intentional steps;
9. stop a rep before collapse;
10. understand that the leverage ladder is a lifelong spectrum, not a checklist to rush through.

If these criteria are not met, repeat Weeks 5–8 using the leverage that currently fits the trainee.

---

# 15. Simple workout card

## Before every work rep

**SET → ASSIST → BRACE → FIGHT → ESCAPE → RESET**

## During the eccentric

Ask:

- Am I trying to stop?
- Is the path still clean?
- Can I escape immediately?

If yes, continue.

If no, end the rep.

## After the session

Record:

- exercise;
- leverage variation;
- Blue / Orange / Red;
- number of quality reps;
- approximate descent character (controlled / stoppable / too fast);
- soreness the next day.

---

# 16. Important interpretation note

This program deliberately does **not** prescribe very high volumes or frequent supramaximal exposures.

The most important beginner adaptation is not simply stronger muscle. It is learning to judge leverage, tolerate eccentric loading, control the movement path, and distinguish productive overload from excessive loading.

That skill makes later progression much safer and more useful.

---

# 17. Safety disclaimer

This is general educational programming, not individualized medical advice.

High-force eccentric exercise may be inappropriate for some injuries, recent surgeries, tendon disorders, cardiovascular conditions, or other medical limitations.

If pain is unusual, sharp, neurological, or persistent, stop the exercise and seek appropriate professional evaluation rather than modifying around it indefinitely.
