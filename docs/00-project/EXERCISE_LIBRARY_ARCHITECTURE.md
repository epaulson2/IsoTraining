# Exercise Library Architecture

## Purpose

The library is organized around **movement / position families**, not a flat list of unrelated exercises. Each family may contain:

1. **Integrated Extreme Iso** — whole-body positional control, stabilization and force distribution.
2. **Targeted Extreme Iso** — usually strap- or support-assisted, with precise joint-angle control and focused muscular intent.
3. **Learning regressions** — easier positions used to acquire the geometry and contraction strategy.
4. **Advanced variations** — longer duration, greater leverage, external load, Extreme Slow, rebound or reactive integration where appropriate.

## Provenance labels

Every exercise or technical cue should be tagged as one of:

- **SCHROEDER / EVO ORIGINAL** — directly described in Schroeder/EVO material or documented by trainees receiving EVO instruction.
- **SCHROEDER-DERIVED** — close coaching interpretation that preserves the original principles.
- **EVIDENCE-BASED EXTENSION** — our own application of long-muscle-length / isometric principles and established biomechanics.

No extension should be presented as something Schroeder personally taught unless the source supports that claim.

## Post-audit programming tiers

The 2026-09-10 whole-library audit established three practical tiers so that the system does not become a catalog of equally weighted variations.

### Tier A — Programming Core
Movements with the strongest combination of historical importance, distinct training value, technical clarity and programming usefulness. Beginner and intermediate programs should be built primarily from this tier.

### Tier B — Secondary / Developmental
Useful exercises that solve a specific need, add a distinct stimulus, serve as a progression/regression, or become valuable after the trainee has mastered the core.

### Tier C — Optional / Accessory
Technically usable movements that are redundant, highly isolated, equipment-dependent, or insufficiently distinct to deserve routine programming. These remain documented but are not default program content.

See [Exercise Master List](../02-exercises/EXERCISE_MASTER_LIST.md) and [Whole-Library Technical Audit](../01-research/WHOLE_LIBRARY_TECHNICAL_AUDIT_2026-09-10.md).

## Validation standard

A candidate exercise enters the final library only if we can define:

- stable setup and body geometry;
- weight / pressure distribution;
- primary muscular action;
- intended force direction;
- what must remain stationary;
- target sensation and acceptable secondary tension;
- depth / range criteria;
- common compensations;
- safe entry and exit;
- regression and progression;
- provenance and evidence level.

For an **evidence-based extension**, it must additionally pass four questions:

1. Is the intended tissue meaningfully lengthened or the target joint angle otherwise purposeful?
2. Can the trainee actively produce force rather than merely hang on passive structures?
3. Can the joints remain in a mechanically reasonable, repeatable position?
4. Can the exercise be regressed and progressively overloaded?

## Programming philosophy

Difficulty should not be defined mainly by adding endless new exercises. A family can progress through:

**Assisted position → standard Extreme Iso → longer accumulated work → loaded / harder leverage → Extreme Slow → force-absorption / rebound integration → reactive expression**

Two variables must remain distinct:

- **Duration / accumulated time**
- **Contraction intensity / intent**

A long hold is not automatically a maximal-intent hold, and maximal-intent work does not automatically need long duration.

Programming will now be written from the audited Tier A core, with Tier B used selectively and Tier C reserved for special cases.
