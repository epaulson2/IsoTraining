# IsoTraining Whole-Library Technical Audit

**Date:** 2026-09-10

## Executive conclusion

The 13-family architecture is sound and should be retained, but the exercise inventory should not treat every listed variation as equally important. The library works best as a **tiered system**:

1. **Programming Core** — movements that define the system and should drive beginner/intermediate programming.
2. **Secondary / Developmental** — useful movements introduced selectively for balance, progression, or a distinct regional stimulus.
3. **Optional / Accessory** — technically valid but redundant, highly isolated, equipment-dependent, or not central enough to deserve routine programming.

The audit also identified one important biomechanical classification error: the historical standing straight-leg raise should **not** be described as a long-length quadriceps exercise. Hip flexion shortens rectus femoris proximally while knee extension shortens it distally. The position is better classified as an **anterior-chain / hip-flexor + knee-extension control position**. The supported sissy-squat is the stronger long-length quadriceps candidate.

## Evidence principles used in this audit

- Schroeder/EVO provenance is preserved where historically supportable.
- Modern extensions are judged by repeatable geometry, active force intent, useful muscle/joint position, regressability, overloadability, and whether they add something not already provided by another exercise.
- Long-muscle-length isometrics are useful, but long length is not a requirement for every exercise. The 2019 systematic review by Oranchuk et al. found advantages for longer-length isometrics in hypertrophy and transfer, while also showing that intensity and intent independently alter adaptation. High-intensity contractions are particularly relevant to tendon adaptations. https://pubmed.ncbi.nlm.nih.gov/30580468/
- A 2025 controlled trial found long-muscle-length isometric knee extension can produce meaningful quadriceps hypertrophy, supporting the inclusion of a true long-length quadriceps option. https://pubmed.ncbi.nlm.nih.gov/40911904/
- Copenhagen adduction has sufficient independent support to remain as the targeted adductor exercise. A 2021 systematic review found improvements in adductor strength and activation; a 2026 modeling study ranked long-lever Copenhagen among the highest-force exercises for the adductors. https://pubmed.ncbi.nlm.nih.gov/34631242/ and https://pubmed.ncbi.nlm.nih.gov/41931009/
- The 2025 Copenhagen meta-analysis should **not** be used because it was retracted in 2026 for analytical and methodological problems. https://pubmed.ncbi.nlm.nih.gov/41975640/

## System-level coverage audit

### Sagittal lower body
**Strong coverage.** Lunge, wall squat, single-leg squat, standing hamstring/hinge, calf, and quadriceps-specific work provide more than enough sagittal-plane options.

### Frontal plane
**Previously a gap; now adequately covered.** The supported lateral lunge/Cossack provides the integrated position; Copenhagen provides the targeted adductor option.

### Horizontal push/pull
**Balanced.** Extreme push-up + strap chest press are strong. Body-supported row + strap row provide the missing horizontal pull pattern.

### Vertical push/pull
**Adequate but should remain selective.** Scapular pull-up/hang is a core historical position. The dip is valuable but better treated as advanced. A separate strap overhead press is not essential.

### Elbow flexion/extension
**Well covered.** Historical preacher curl plus strap curl; overhead strap triceps gives a useful lengthened triceps option.

### Shoulder rotation/stability
**Useful as accessory work, not a major programming pillar.** External rotation has the clearest unique role. Internal rotation is valid but overlaps heavily with chest/lat/subscapular loading elsewhere.

### Ankle/foot
**Adequate.** Straight-knee and bent-knee calf positions cover gastrocnemius/soleus emphasis. A separate strap calf version is optional rather than core.

### Tier A — Programming Core

2. Iso-Extreme Wall Squat — EVO Original
3. Standing Glute-Ham / Standing Hamstring Iso — EVO Original
4. Extreme Push-Up — EVO Original
5. Scapular Pull-Up / Active Hang Extreme Iso — EVO Original
6. Preacher Curl Extreme Iso — EVO Original
7. Strap Extreme Chest Press — Evidence-Based Extension
8. Body-Supported Row Iso — Evidence-Based Extension
9. Straight-Knee Calf Iso — Evidence-Based Extension
10. Bent-Knee Calf Iso — Evidence-Based Extension
11. Supported Lateral-Lunge / Cossack Iso — Evidence-Based Extension
12. Strap Overhead Triceps Iso — Evidence-Based Extension
13. Strap External-Rotation Iso — Evidence-Based Extension
14. Supported Sissy-Squat Iso — Schroeder-derived / later associated use

### Tier B — Secondary / Developmental
Useful when the trainee is ready or when a specific training need exists.

1. Iso-Extreme Single-Leg Squat — EVO Original / historical variants
2. Standing Push-Off / Standing Push-Up — EVO-associated; also a learning regression
3. Assisted Scapular Hang / Pull-Up — learning regression / developmental
4. Strap Row Iso — targeted horizontal pull
5. Strap Curl Iso / Long-Length Strap Curl — targeted elbow-flexion work
6. Copenhagen-Style Adductor Iso — targeted higher-intent adductor work
7. Strap Hip-Flexor Iso — targeted hip-flexor strength
8. Supported Long-Split Hip-Flexor Iso — positional/long-length hip-flexor control
9. Standing Straight-Leg Raise Iso — historical anterior-chain position; **reclassified, not long-length quadriceps**
10. Strap Knee-Extension Iso — targeted quadriceps option
11. Dip Extreme Iso — advanced integrated press
12. Strap Lat Pulldown / Straight-Arm Pull — targeted lat option
13. Overhead Shoulder-Stability Iso — accessory integrated shoulder control

### Tier C — Optional / Redundant Accessories
Keep documented, but do not build standard programming around them unless later testing reveals a specific reason.

1. Strap-Assisted Targeted Split-Stance Iso — useful but largely duplicates lunge force intent once balance competency exists.
2. Strap-Assisted Knee-Dominant Iso — useful for targeted force but redundant with wall squat/single-leg squat/strap knee extension.
3. Strap-Assisted Targeted Hinge Iso — potentially useful, but standing hamstring plus curl variant already cover most needs.
4. Strap Hamstring-Curl Iso — valid isolation option, but secondary to the standing hamstring position.
5. Strap Overhead Press Iso — **recommend removing from standard library/programming core**; little unique Extreme-Iso value beyond press/dip/shoulder-stability work.
6. Long-Arm Strap Row / Scapular Retraction Iso — useful cueing/accessory option but not necessary as a distinct programmed exercise.
7. Strap-Assisted Calf Iso — redundant unless bodyweight loading cannot be scaled appropriately.
8. Strap Adduction Iso — redundant once lateral-lunge/Cossack + Copenhagen are available.
9. Rear-Leg Active Split Iso — should be treated as a **variation/cue within the split-stance/hip-flexor families**, not as a separate canonical exercise.
10. Strap Internal-Rotation Iso — valid accessory, but not necessary in standard programs because internal rotators receive substantial work from pressing/pulling; retain for balance/rehab-specific use rather than routine inclusion.

## Exercise-specific audit notes

### Split stance / lunge
**Keep.** This remains one of the signature integrated positions. The targeted strap split-stance version should be optional, not co-equal with the original.

### Squat / knee-dominant
**Keep wall squat and single-leg squat distinct.** They have different geometry and stabilization demands. Supported deep squat remains a learning bridge, not a canonical workout movement.

### Hip hinge / hamstring
**Keep standing hamstring as the anchor.** It provides integrated posterior-chain control. Strap hinge/curl work is useful but should not crowd out the original.

### Horizontal push
**Excellent pairing:** Extreme Push-Up for integrated stabilization + Strap Chest Press for targeted high-intent force. Retain both.

### Vertical push / triceps
**Simplify.** Keep dip as advanced and strap overhead triceps as the targeted staple. Demote/remove the strap overhead press from standard programming.

### Vertical pull / scapular-lat
**Keep active hang/scapular position as core.** Do not over-prescribe exact scapular depression because the historical geometry is incompletely documented and individual shoulder anatomy varies. Strap lat pull is useful secondary work.

### Horizontal pull
**Keep body-supported row and strap row.** Treat long-arm retraction as a cue/variation, not a required third exercise.

### Biceps
**Keep historical preacher curl.** The strap curl is useful because it allows angle selection. If we explicitly want a long-muscle-length biceps variant, use shoulder extension plus a relatively extended elbow rather than assuming a preacher position is globally long-length.

### Calf / ankle
**Keep straight-knee and bent-knee versions.** Ankle position meaningfully changes triceps-surae mechanics and recruitment. Current research supports the relevance of muscle-tendon length manipulation, though not every finding is specific to our exact protocol. https://pubmed.ncbi.nlm.nih.gov/40421865/

### Adductor / lateral stance
**Keep two complementary exercises:** lateral lunge/Cossack for integrated frontal-plane control; Copenhagen for targeted adductor strength. Demote strap adduction as redundant.

### Hip flexor / long split
**Keep, but do not oversell as a required core family.** It fills a real tissue/position gap, yet the rear-leg active split overlaps with the Extreme Lunge. Merge that concept into the long-split tutorial instead of treating it as a separate canonical exercise.

### Shoulder rotation / stabilization
**Keep external rotation.** Internal rotation and overhead stabilization remain optional/secondary. The family is useful for completeness but should not consume much beginner programming volume.

### Anterior chain / quadriceps
**Rename/reframe.** Standing straight-leg raise is historical but not a long-length quadriceps exercise. Supported sissy-squat is the long-length quad anchor; strap knee extension is the precise targeted option. The family should be titled **Anterior Chain / Quadriceps** rather than Quadriceps Long-Length.

## Learn Mode audit

The current Learn Mode sequence is strong. Across the library, final tutorials should enforce the same order:

1. Safety and equipment setup
2. Base geometry
3. Joint alignment
4. Rib-cage/pelvis/spine organization
5. Pressure distribution
6. Working depth / angle
7. Primary muscular action
8. Opposing/stabilizing action
9. Combined force vector
10. Extreme-Iso intent
11. Short competency hold
12. Controlled exit

Every exercise should also retain the three checkpoints:

- **Visual:** does the position look correct?
- **Tension:** is muscular work occurring where intended rather than as passive joint pressure?
- **Intent:** is the trainee actively attempting the prescribed force direction?

## Safety / precision audit

- Avoid universal joint-angle mandates when historical evidence is weak or anatomy varies.
- “Extreme” means the deepest/longest **actively controllable** position, not maximal passive range.
- Maximal intent should not be introduced until geometry is stable.
- Long-duration work and maximal-intent work are distinct programming variables; they should not automatically be combined.
- Tool-assisted isometrics require structurally sound straps/anchors and gradual force ramp-up.
- Stop criteria should include sharp pain, pinching, neurological symptoms, or transition from muscular loading to passive joint loading.

## Locked architecture after audit

Retain all **13 movement families** for educational completeness, but program from a smaller Tier A core and selectively use Tier B. Tier C remains documented as variations/accessories rather than routine exercises.

This preserves what is distinctive about Schroeder-style work — integrated extreme positions and internal force intent — while using strap work where it genuinely adds precision instead of turning the system into a catalog of isolated overcoming isometrics.
