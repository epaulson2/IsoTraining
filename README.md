# IsoTraining

Research and development repository for an evidence-informed Extreme Isometric training system inspired by Jay Schroeder / EVO methods and expanded with modern isometric training principles.

## Project goals

- Preserve a clear distinction between **Schroeder/EVO original material**, **Schroeder-derived coaching practice**, and **our own evidence-based extensions**.
- Build a validated exercise library before writing full programming.
- Create two usage layers for every movement:
  - **Learn Mode** — detailed step-by-step positional learning.
  - **Workout Mode** — compact execution cues once the position is mastered.
- Balance **integrated bodyweight positions** with **targeted strap-assisted isometrics**.
- Use the exercise specifications as the source of truth for future beginner, intermediate, advanced programming and the final PDF/manual.
