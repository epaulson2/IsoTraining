# Beginner Visual Assets

## Status

The beginner visual set contains **24 finalized assets** organized into four groups:

- `exercise-plates/` — 14 canonical exercise plates
- `learn-mode/` — 6 step-by-step learning visuals
- `session-maps/` — Sessions A, B, and C
- `guides/` — force-arrow / diagram legend

> Binary upload note: the ChatGPT GitHub connector currently exposes text-file writes and Git-object primitives but no direct binary-file upload action. The 24 image files have been generated, optimized, and packaged in the working artifact `IsoTraining_Beginner_Visual_Pack.zip`; this manifest records the canonical repository paths so the pack can be committed without renaming or ambiguity when binary transfer is available.
