# Home Eccentric Overload Visual Assets

This directory stores the visual package for the Home Eccentric Overload / Core 6 system.

## Structure

- `universal/` — method, calibration, safety and leverage-ladder system graphics
- `core-6/01-ring-chest-press/` — Learn Mode, leverage ladder and workout plate
- `core-6/02-ring-row/` — Learn Mode, leverage ladder and workout plate
- later Core 6 exercise assets follow the same naming convention

## Canonical naming

Universal:
- `EO01_method_overview.webp`
- `EO02_calibration_zones.webp`
- `EO03_safety_escape_rules.webp`
- `EO04_leverage_ladder.webp`

Per exercise:
- `LM##_*` = Learn Mode
- `LL##_*` = Leverage Ladder
- `WP##_*` = Workout / Quick Reference

Repository copies use optimized WebP. Source-quality generated images should be retained separately for final publication assembly.
